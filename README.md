# Epay - Mobile Banking App

A modern, secure mobile banking application built with React Native for seamless financial management.

## Features

- 🔐 Secure user authentication
- 💳 View account balance and details
- 💸 Money transfers between accounts
- 📊 Transaction history and analytics
- 📱 Responsive mobile interface
- 🎯 Bill payment management
- 💰 Savings goals tracker

## Project Structure

```
epay/
├── src/

│   ├── utils/
│   ├── styles/
│   └── App.js
├── assets/

└── README.md
```

## Installation

```bash
npm install
npm start
```

## Technologies

- React Native
- Redux for state management
- Firebase for authentication
- Axios for API calls
